# 📄 Formulario Linters

¡Bienvenido al proyecto **Formulario Linters**!  
Este repositorio contiene un formulario web desarrollado con **HTML**, **CSS**, **JavaScript** y empaquetado con **Webpack**, incorporando además buenas prácticas de **linters** como **ESLint** y **Stylelint** para mantener un código limpio y profesional.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Webpack
- ESLint (con la guía de estilo Airbnb)
- Stylelint (con configuración estándar)

---

## 📦 Instalación del proyecto

Sigue estos pasos para clonar y ejecutar el proyecto localmente:

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/NicolasMendez30/Formulario-Linters.git
   cd Formulario-Linters
   ```

2. **Instala las dependencias**:
   ```bash
   npm install
   ```

3. **Ejecuta el proyecto en modo de desarrollo**:
   ```bash
   npm start
   ```

4. **Compila el proyecto para producción**:
   ```bash
   npm run build
   ```

---

## 🧹 Linters

Este proyecto utiliza linters para mantener la calidad del código:

- **ESLint** para JavaScript:
  ```bash
  npx eslint .
  ```

- **Stylelint** para CSS:
  ```bash
  npx stylelint "**/*.{css,scss,sass}"
  ```

- **Auto-corrección de errores**:
  ```bash
  npx eslint . --fix
  npx stylelint "**/*.{css,scss,sass}" --fix
  ```
